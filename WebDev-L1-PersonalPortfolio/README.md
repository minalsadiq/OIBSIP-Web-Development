# 📄 Personal Portfolio — Minal Sadiq
**OASIS INFOBYTE Internship — Web Development & Designing — Level 1, Task 2**

## Objective
A personal portfolio website showcasing skills, projects, and contact information —
built from scratch in plain HTML/CSS as required by this task's tech stack, using **real**
content (name, skills, live projects) rather than filler placeholder text.

## Tech Stack
HTML5 · CSS3 (Flexbox + Grid, no JavaScript required beyond native smooth-scroll)

## Design Notes
- **Palette:** deep charcoal navy (`#12161F`) base with an amber accent (`#E8A33D`) and a
  muted teal secondary (`#4FB0A5`) — a technical, data/AI-appropriate feel without falling
  back on the generic neon-green-on-black look.
- **Type:** `Space Grotesk` for headings (a geometric, slightly technical display face) paired
  with `IBM Plex Sans` for body text.
- **Avatar:** a gradient initials mark (MS) rather than a placeholder photo, since no real
  headshot was supplied — this keeps the hero honest rather than using a stock photo.

## Feature Checklist Coverage
- Hero/profile section: name, role title, initials avatar
- About Me section (2–3 sentences on background/interests)
- Skills section as a 4-category grid
- Projects section with 4 real project cards (title, description, GitHub link, live demo link)
- Contact section: email, LinkedIn, GitHub, WhatsApp
- Smooth-scroll navigation between sections (`scroll-behavior: smooth`)
- Consistent branding (colour scheme + font family) throughout
- Fully responsive — tested at 1400px and 390px widths

## Content Source
Skills, project descriptions, and contact details are taken from the person's own existing
portfolio content, rebuilt here in plain HTML/CSS to satisfy this task's specific tech-stack
requirement.
